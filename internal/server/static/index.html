Security Architecture & Boundary Model

Radar enforces least-privilege containment to safely execute untrusted instructions dispatched by autonomous AI agents.

🛡️

Least-Privilege Containment

Every tool operates in a sandboxed, in-memory execution perimeter. No child processes, no disk writes, no network socket escalation.

  • AST Parsing strictly parses Go source into read-only in-memory syntax trees.
  • Math parsing runs purely via an AST lexer without eval() or syscalls.
  • Regex execution enforces max line limits and byte caps to prevent ReDoS.
🔑

Multi-Token Bearer Authentication

Constant-time token comparison prevents timing side-channel attacks. Configure via comma-delimited environment variable:

RADAR_AGENT_TOKENS=tok-alpha,tok-beta,tok-prod

Pass token in HTTP headers: Authorization: Bearer <token>

🌐

W3C Distributed Tracing

Radar adheres to the W3C Trace Context recommendation (traceparent header):

traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01

Injected automatically in downstream responses via X-Trace-Id.

⚡

Zero-Allocation Patterns

Hot path operations leverage pre-allocated sync.Pool buffers and byte slice re-use to eliminate garbage collection pauses.

Deploying Radar on Render

Radar is a statically linked Go microservice in a distroless container. Deploy on Render in under 2 minutes.

1

Method A: One-Click Render Blueprint (Recommended)

Radar includes a production-ready render.yaml blueprint file in the repository root. Render reads this file and automatically configures the web service, Docker build, environment variables, and health checks.

render.yaml
services:
  - type: web
    name: radar-agent-service
    env: docker
    dockerfilePath: Dockerfile
    plan: standard
    region: oregon
    healthCheckPath: /health
    envVars:
      - key: RADAR_ENV
        value: production
      - key: RADAR_PORT
        value: 8080
      - key: RADAR_AGENT_TOKENS
        generateValue: true
      - key: RADAR_RATE_LIMIT
        value: 100
      - key: RADAR_RATE_BURST
        value: 200
2

Method B: Manual Web Service Setup via Render Dashboard

  1. Log in to the Render Dashboard and click New + > Web Service.
  2. Connect your Git repository containing Radar.
  3. Set Environment to Docker. Render automatically detects the root Dockerfile.
  4. Set Instance Type to Free or Starter.
  5. In Advanced > Health Check Path, enter: /health
  6. Under Environment Variables, configure:
    • RADAR_PORT: 8080 (Render forwards inbound traffic to this port)
    • RADAR_ENV: production
    • RADAR_AGENT_TOKENS: your-secure-agent-token-here
  7. Click Create Web Service. Render builds the multi-stage image and goes live!
